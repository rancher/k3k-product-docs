= SUSE Virtual Cluster v1.2.0 Release Highlights
:revdate: 2026-02-23
:page-revdate: {revdate}

== New Features

* *HCP (Hosted Control Plane) mode (experimental)* -- a new virtual cluster mode that provisions an agentless K3s control plane in the host cluster while letting you join your own external worker nodes via the standard K3s installer. See xref:how-tos-for-user/create-hcp-virtual-cluster.adoc[Creating an HCP Virtual Cluster].

== Core Improvements

* *Custom annotations on the exposed Service* -- `expose.annotations` lets you set custom annotations on the Service generated for `expose.loadBalancer` or `expose.nodePort`, useful for cloud-provider-specific load balancer configuration. See xref:advanced-usage.adoc#_expose[Advanced Usage: expose].
